Workshop Uploader

Workshop Uploader is a private tool that publishes videos to YouTube channels run by its owner. It is not offered to the public and has no other users.

What it does

  • Uploads a finished video file to one of the owner's own YouTube channels.
  • Sets the title, description, tags, visibility and thumbnail the owner wrote for it.
  • Posts the owner's own first comment under the video.

How it uses YouTube

It uses the YouTube Data API Services, and only after the channel owner signs in with Google and grants access. It asks for permission to upload videos and to manage comments on the owner's channel. It does not read, collect or store data about any other YouTube user.
